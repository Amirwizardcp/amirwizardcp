# AmirWizardCP

یک فروشگاه استاتیک و واکنش‌گرا برای نمایش بسته‌های CP کالاف دیوتی موبایل.

## اجرا
فایل `index.html` را در مرورگر باز کنید یا کل پوشه را روی یک میزبان سایت استاتیک منتشر کنید.

## امکانات
- نمایش ۸ کارت محصول (۴ بسته با قیمت‌های واردشده و ۴ جایگاه غیرفعال تا زمان تأیید مشخصات)
- سبد خرید و محاسبه جمع
- ساخت متن سفارش و هدایت به روبیکا
- طراحی واکنش‌گرا برای موبایل و دسکتاپ

## مواردی که قبل از فروش واقعی باید تکمیل شوند
1. قیمت‌های چهار بسته اول را دوباره تأیید کنید؛ اعداد فعلی از اطلاعات قبلی پروژه وارد شده‌اند و قطعی فرض نشده‌اند.
2. مشخصات و قیمت چهار بسته سفارشی را در `app.js` وارد و `disabled:true` را حذف کنید.
3. این نسخه درگاه پرداخت، پایگاه داده، پنل مدیریت امن یا ثبت سفارش سمت سرور ندارد. سبد خرید فقط در مرورگر کاربر فعال است.
4. برای استفاده عمومی، سایت را روی میزبان HTTPS منتشر کنید و سیاست حریم خصوصی/قوانین فروش را تکمیل کنید.
